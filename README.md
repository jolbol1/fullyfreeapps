# Fully Free Apps

Company website for Fully Free Apps, a trading name of MWD Studios Ltd.

## Develop

Use Node 22.13 or newer. Run `npm ci`, then `npm run dev`.

## Validate and deploy

Run `npm run lint`, `npx tsc --noEmit`, and `npm run deploy`. Deployment uses Wrangler directly with the configuration generated by the production build in `dist/server/wrangler.json`.

The Worker is `fullyfreeapps` and serves `fullyfreeapps.com` and `www.fullyfreeapps.com`. The source of deployment configuration is `wrangler.jsonc`. Compatibility date 2026-09-04 is the latest supported by the installed runtime.

## Content

- `/`: company and free-app promise
- `/slate`: app details and release status
- `/support`: help and contact
- `/privacy`: app, website and support-email privacy

All fonts and assets are local. No advertising or analytics scripts are added. Worker invocation logs are disabled; Cloudflare still processes requests to host and protect the site.

## Email

Cloudflare Email Routing forwards support@fullyfreeapps.com and developer@fullyfreeapps.com to the verified company inbox. Routing is configured in Cloudflare’s dashboard, not in the website. Outbound replies need a mailbox/send-as service if they should come from those aliases.

## Apple enrollment status

The website is deployed and both email aliases are active. Apple enrollment is at the personal-information step. D-U-N-S lookup, organization verification, name confirmation, program agreement/payment, App ID, App Store Connect record and app submission remain outstanding. Do not create the first app record until the permanent developer name is decided.
